# 第 9 课：让奖励教会控制——强化学习与 Q-learning

[上一课：ROS 与 SDK 数据桥](lesson_08_zh.md) · [学习路线](learning_path_zh.md) · [下一课：看懂 PPO](lesson_10_zh.md)

前八课从模型与反馈出发计算控制量；本课换一个入口：让程序反复尝试动作，根据后果更新一张“这个动作值得做吗”的表。完成后，你应能解释状态、观测、动作、奖励与回报，手算一次 Q 更新，并用留出评估判断一次小规模学习是否有进步。预计 60～90 分钟。

先修是第3课的反馈误差、第7课的一步状态预测，以及 Python 的列表、字典、循环和函数。实验只用标准库与已有教学 Docker 镜像；不用安装 Gymnasium、PyTorch 或 GPU 驱动。Gazebo 可以关闭。本课的速度是离散教学数，没有腿、接触或电机，不是 AlienGo 训练环境。

## 1. 先把一次交互说清楚

把环境想成一个接受动作、返回下一观测和评分的程序：

```text
当前观测 o_t → 策略选动作 a_t → 环境推进一步
                    ↓
下一观测 o_(t+1)、奖励 r_t、terminated、truncated
                    ↓
            更新学习结果，或开始新回合
```

本课把“执行动作之后得到的奖励”记成 `r_t`；一些书写 `R_(t+1)`，只是下标习惯不同。

| 名词 | 通俗解释 | 本课实例 |
|---|---|---|
| 状态 state，`s` | 知道它和动作后，便足以描述下一步的分布 | 当前速度档 `velocity` 与目标档 `command` |
| 观测 observation，`o` | 策略实际拿到的信息 | 完整看到上述两项，所以这里 `o=s` |
| 动作 action，`a` | 这一步让环境做什么 | 保持、减一档、加一档 |
| 转移 transition，`P` | 动作与随机扰动如何改变状态 | `v_next = v + action + wind` |
| 奖励 reward，`r` | 刚才这一步获得的标量评分 | 速度误差、动作大小与越界惩罚合成一个数 |
| 策略 policy，`π` | 给定观测时如何选动作 | 训练时带探索；评估时取 Q 最大的动作 |
| 回合 episode | 从 reset 到任务结束或采集停止的一段交互 | 随机初始速度和目标，最多收集40步 |

这就是一个小型马尔可夫决策过程（MDP）：状态集合、动作集合、转移规律、奖励规律和折扣因子共同定义问题。“马尔可夫”不是说未来不受过去影响，而是说**给定现在的状态和动作后，无需再知道完整历史来预测下一步的分布**。本课风扰动每步独立，目标在一个回合中固定，所以这两项状态足够。

真实四足机器人通常只测到部分信息：电机温度、地形、接触、载荷或精确速度可能隐藏或有噪声。因此观测一般不等于完整状态；观测历史和状态估计都有实际作用。只给本实验策略“当前速度”、藏起目标，也会让同一个观测对应两个相反任务。

Q-learning 从尝试动作的结果更新动作价值，无需先知道转移概率。这里公开环境公式是为了方便检查；学习器没有把它用于预测最优动作。[Watkins 与 Dayan，1992 年原论文](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf)

## 2. 读懂这份很小的“速度任务”

打开 [q_learning_speed.py](../examples/lesson09/q_learning_speed.py)，先看文件开头的常量。

| 教学量 | 数值与含义 |
|---|---|
| 一个速度档 | `0.2 m/s` |
| 非终止速度档 | `−3,−2,−1,0,1,2,3`，即 `−0.6～+0.6 m/s` |
| 目标档 | `−2,−1,+1,+2`，即 `−0.4,−0.2,+0.2,+0.4 m/s` |
| 时间间隔 | 每步代表 `0.2 s` |
| 动作档 | `0,−1,+1`，等价于本模型 `0,−1,+1 m/s²` 作用一个时间间隔 |
| 风扰动档 | 每步独立取 `−1,0,+1`，概率 `0.1,0.8,0.1` |
| 初始条件 | reset 时均匀抽一个非终止速度档和一个目标档 |
| 采集上限 | 默认40步，即最多8秒模型时间，不需要等待8秒现实时间 |

共有 `7×4=28` 个非终止状态，每个状态有3个动作，只需84个 Q 数值。速度超出 `[-3,3]` 就进入失败终止结果，保留真实越界值，不把速度夹回范围里冒充成功。这个人为边界属于教学任务，不能当作真实机器人速度上限。

每一步用**执行动作并受到风扰动之后**的速度评分，全部以“档”为单位代入：

```text
v_next = velocity + action + wind
reward = 1 − 0.25 × (v_next − command)² − 0.05 × |action|
如果 v_next 越界，再减5，并 terminated=True
```

奖励是无量纲教学评分。误差项也可写成 `0.25×((v_next_m_s−command_m_s)/0.2)²`。追上目标且不动作得到1；奖励为正不表示任务已经完成，速度跟踪还要继续。

**先手算：** 现在速度0、目标2、动作+1、没有风。新速度1档，即 `0.2 m/s`；误差 `−1` 档，奖励 `1−.25−.05=.70`。如果速度已经3档仍加一档，没有风也会越界到4档，奖励 `1−.25×(4−2)²−.05−5=−5.05`，并真正结束回合。

## 3. 奖励是眼前一分，回报是一串分

强化学习通常优化期望回报，而不是每一步都拿眼前最大的奖励。折扣回报把未来奖励乘上逐渐缩小的权重：

```text
G_t = r_t + γ×r_(t+1) + γ²×r_(t+2) + …
```

`γ`（gamma）在0到1之间。γ=0只看眼前；接近1时更重视远期。对持续任务，γ<1也让有界奖励的无限和保持有限。它不是物理时间步长：改变每步代表的时间而保留γ，会改变每秒折扣的程度。

例如奖励 `[1,2,3]`、γ=.5，从第一步算：`G_0=1+.5×2+.25×3=2.75`，`G_1=2+.5×3=3.5`，`G_2=3`。代码 `discounted_returns()` 从最后一步往前递推，避免反复求幂。

Q 表的 `Q(s,a)` 估计“从状态s先做动作a，此后选好动作，还能得到多少折扣回报”。它用一次经验修正旧估计：

```text
target = reward + γ × max_a Q(next_state, a)   # 非终止，包括外部超时
target = reward                               # 真正终止
Q_new = Q_old + α × (target − Q_old)
```

`α`（alpha）是学习率；`target−Q_old` 是时间差分误差。借用下一状态的价值估计更新当前估计叫 **bootstrap**。例如旧值2、奖励1、下一状态最大 Q=4、γ=.9、α=.5，普通转移的目标是4.6，更新后3.3；真正终止时目标是1，更新后1.5。本实验使用有限次数、固定学习率和探索率，不以原论文在特定条件下的收敛定理保证已经最优。

## 4. 回合停止时，为什么要两个标志

| 标志 | 本课何时为真 | Q 更新还用下一状态价值吗？ |
|---|---|---|
| `terminated` | 速度越界，任务定义的失败 | 不用；未来任务价值为0 |
| `truncated` | 没越界，但收集到了第40步 | 要用；如果继续跟踪仍会有未来奖励 |

本任务本来可以一直跟踪，40步只是一条外部采集预算，所以时间到是截断。代码在两种情形都会 reset，但只有真正终止会去掉 bootstrap。要使用的是 **reset之前的最后观测**，不能拿新回合的初始观测估值。若任务本身规定“必须在40步内完成”，那么到时属于任务终止，而且观测需要包含剩余时间来维持马尔可夫性。[Gymnasium：Handling Time Limits](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

## 5. 实跑：先比较未训练基线，再谈进步

```bash
cd /home/jack/aliengo_learning
./scripts/ros1_course.sh offline lesson09/q_learning_speed.py --help
./scripts/ros1_course.sh offline lesson09/q_learning_speed.py
```

容器由统一入口以 `--network none` 启动，计算只在本地进行。默认命令实跑输出如下：

```text
train seed=7 episodes=3000 horizon=40 alpha=0.15 gamma=0.95 epsilon=0.2
held-out evaluation seeds=10000..10099 greedy=True updates=False
policy       mean_return    MAE(m/s)    terminal%    mean_steps
untrained      -10.15959     0.41141        50.00         28.22
trained         14.77693     0.05245         0.00         40.00
return = sum(gamma**t * reward_t) over the collected episode; no evaluation bootstrap
```

基线是全零 Q 表，三个动作同分时固定先选 `0`，所以它是“始终保持”的未训练策略。训练中 ε=.2 表示20%概率均匀随机选动作，其余取当前 Q 最大动作；不是20%概率必然做错。评估时关闭探索，也不更新表。

`mean_return` 是每个采集回合的折扣奖励和，再对100回合取平均；它不额外补终点估值，因此是有限采集段的指标。训练中的 Q 目标则会在截断处 bootstrap，两者用途不同。`MAE(m/s)` 是已采集步的平均绝对速度误差，`terminal%` 是越界失败回合比例，`mean_steps` 是平均回合长度。提前失败会改变误差统计的样本，必须一起看这几列。

训练用 seed=7；两次评估各自重建 `10000～10099` 的100个随机数生成器，使基线与训练后的策略面对同一批初始条件与风序列。留出的是随机种子，状态范围、奖励和风分布仍然相同，不能据此声称对陌生地形具有泛化能力。这个固定实验的回报从约−10.16提高到14.78、误差减小且无越界，支持“本教学任务上有进步”；100回合没有失败并不是任何情况下都不会失败的证明。

原始执行记录保存在 [foundations-report.md](reports/rl-foundations.md)。在相同 Python 环境、相同代码与参数下重跑应复现这些数值；更换算法或随机源实现后应重新记录。

## 6. 一次只改一个变量

先预测：把训练从3000回合减到100回合，误差与回报是否必须按比例变差？

```bash
./scripts/ros1_course.sh offline lesson09/q_learning_speed.py --episodes 100
```

实测训练后 `mean_return=13.00786`、`MAE=0.12140 m/s`、`terminal%=0`。比未训练好，但误差高于3000回合的 `.05245 m/s`。学习不是线性进度条；个别 seed 或训练长度也未必单调改善，不能只挑最好的一次结果。

再把同一个参数改成0，预测两行是否完全一样：

```bash
./scripts/ros1_course.sh offline lesson09/q_learning_speed.py --episodes 0
```

这次两行实测都为回报 `−10.15959`、误差 `.41141 m/s`、失败率50%、长度28.22。它检查了“改进确实需要更新 Q 表”。如果课程代码直接把朝目标的动作写死，这个对照便没有意义。

## 7. 顺着代码读一次学习循环

| 代码位置 | 要回答的问题 |
|---|---|
| `transition()` | 哪一步计算奖励？为什么先算下一速度？ |
| `empty_q_table()`、`greedy_action()` | 字典键为什么同时有速度和目标？全零时选什么？ |
| `q_update()` | 为什么 `truncated` 不会把下一状态的 Q 变成0？ |
| `run_experiment()` | 探索只发生在哪里？为什么先更新再 reset？ |
| `evaluate()` | 为什么不给它学习率？为什么每个回合重建随机数生成器？ |

关键调用是：

```python
next_max = 0.0 if terminated else max(table[(next_velocity, command)])
table[observation][action_index] = q_update(
    table[observation][action_index], reward, next_max,
    alpha, gamma, terminated, truncated)
```

先在下一状态整行动作里取最大值，再只修正当前状态中刚刚选择的那一格。这是表格 Q-learning；没有神经网络，也没有反向传播。下一课将理解连续动作任务里常见的策略网络与 PPO。

## 8. 排错与验收

| 现象 | 首先检查 |
|---|---|
| 命令找不到脚本 | 当前目录是否是项目根目录？路径是 `lesson09/...`，不带 `examples/` 前缀 |
| Docker 报镜像不存在 | 按项目 README 恢复已有教学镜像；不需要为本课另装深度学习包 |
| 每次结果不同 | 是否改了 seed、回合数、代码或 Python 环境？评估有没有误更新 Q 表？ |
| 有奖励仍越界 | 奖励是每步评分；任务失败由 `terminated` 单独定义 |
| 参数被拒绝 | γ与ε须在 `[0,1]`，α在 `(0,1]`；NaN/Inf、负回合数和过大实验预算会被拒绝 |

1. 只把目标从 `.4 m/s` 改成 `−.4 m/s`，当前速度仍是0，为什么只观测速度不够？
2. 旧 Q=2、奖励1、下一最大 Q=4、α=.5、γ=.9，真正终止与外部超时分别更新成多少？
3. 默认训练后的误差更小，是否已经证明策略可以控制 AlienGo？还缺哪些证据？

<details>
<summary>参考答案：先完成自己的解释再展开</summary>

1. 相同速度对应不同目标，应该采取的动作方向可能相反。目标必须在观测里，或者以其他明确方式提供给策略。本模型完整状态就是速度与目标；真实机器人还包含更多隐藏信息。
2. 真正终止不 bootstrap：`2+.5×(1−2)=1.5`。外部超时仍 bootstrap：`2+.5×(1+.9×4−2)=3.3`，使用 reset 前最终状态。
3. 只证明一个28状态教学任务上、同分布留出种子下的数值改进。还缺四足动力学和接触、正确观测/动作契约、训练环境复现、物理仿真评估、推理控制环与部署验证。第11～12课会逐项建立这些边界。
