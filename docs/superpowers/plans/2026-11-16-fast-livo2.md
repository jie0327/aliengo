# FAST-LIVO2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在现有 AlienGo 仿真中运行官方 FAST-LIVO2 三传感器融合并保存可复现验证结果。

**Architecture:** 独立固定版本源码副本、Docker 构建与运行入口。复用已有仿真和 TF 转换数学，通过局部补丁保留瞬时点云时间语义；启动前提取实际相机标定。

**Tech Stack:** ROS1 Noetic, Gazebo11, C++17, Python3, Docker, FAST-LIVO2.

**Spec:** `docs/superpowers/specs/2026-11-16-fast-livo2-design.md`

## Global Constraints

- 官方参考源码不直接修改，所有算法改动保存在 `ros1/patches/fast_livo_sim.patch`。
- 不覆盖现有 Super-LIO 或 GBPlanner 工作区。
- 不伪造仿真点云的扫描时间，不使用真值作为估计器输入。
- 无初始 Git 提交：仅增量文件修改，已有文件修改前备份。

## Review Focus

- 错误或缺失相机标定必须阻止错误融合。
- 瞬时点云在图像切分与 IMU 传播中的时刻一致。
- 工作区重新准备不覆盖用户修改，首次失败可重试。
- 估计 TF 不与 URDF 或真值 TF 形成多个父节点。
- 缺少图像、视觉更新未运行或子进程退出必须令验证失败。
