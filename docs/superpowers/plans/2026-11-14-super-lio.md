# Super-LIO ROS1 接入与验证

**Goal:** 在现有 AlienGo+MID360+Depot 仿真中运行 Super-LIO 的真实估计和建图，保留键盘控制与 ROS1。

**Source:** 官方 ROS1 分支 60b57aaac8dc397f80c56364e7ccb008c300cc29，GPL-3.0。上游已支持真机 MID360 CustomMsg；本地仿真为同一时刻的 XYZ 快照，需要独立、明确的快照输入模式。

**Architecture:** 原参考源码不改，复制到 .super_lio 后应用兼容补丁。独立 Noetic 镜像补齐 PCL/glog/TBB 等依赖；以 -j1、O2、无LTO 有界构建。估计器消费点云+IMU，快照每点时间为0，仍执行原IMU传播、滤波和地图匹配。安装外参沿用物理模型。算法世界名为 lio_map，估计IMU位姿经已知安装外参转换为 base TF；关闭 Gazebo 真值TF。

**Initialization:** 先启动仿真和键盘，按2站稳，再启动LIO，使前50个IMU样本来自稳定状态。控制器和LIO分开启动，避免把落地过程用于重力/偏置初始化。

**Validation:** 比较静止、前进与转向的实际估计，检查注册点云、路径、PCD、运行频率和资源。真值仅评估端一次初始对齐，禁止逐帧校正或注入估计器。使用只含 /clock 与两类传感器的 bag，在无Gazebo环境重放验证。所有构建和仿真串行运行，最终关闭测试进程。
